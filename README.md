An entry for the [Weirdest Job Title: Blind Judge Showdown](https://make.fun/bounty/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922) bounty on [make.fun](https://make.fun).

The program writes a single weird job title — a real-sounding senior role with one hilariously specific twist, about apologizing on behalf of elevators that stop between floors — to `/output/entry.txt`, in 60 characters or fewer and nothing else. A blind AI judge compares titles pairwise and picks the weirder, funnier one.

Run it with:

```sh
python3 main.py
```

It creates `/output` if needed and writes the title to `/output/entry.txt` deterministically (same bytes on every run).
